Why pharma-oss

忙しい薬局の毎日を、ラクに・確実にする4つの特徴。

「入力に時間がかかる」「取り違えや算定漏れが怖い」「毎月のシステム代が高い」——現場でよくある悩みに正面から応える設計です。

POINT 01 — スピードと時短

処方入力も薬歴書きも、毎日の手作業をグッと短縮。

処方箋のQRコードやカメラOCRで受付入力を省力化。薬歴画面では「前回の処方との違い」が自動でハイライトされ、確認項目にチェックを入れるだけでSOAPの下書きが立ち上がるので、閉局後の薬歴残業を減らせます。

処方箋QR・OCR読取 前回Do・処方差分表示 SOAP下書き自動作成 キーボード操作対応
POINT 02 — ヒヤリハット・返戻防止

バーコード照合と多層チェックで、うっかりミスを未然にストップ。

ピッキング時にGS1バーコードを読むだけで「薬品・期限・ロット」の一致を確認。さらに患者さんのアレルギー歴・飲み合わせ（併用禁忌）・同効薬の重複から、レセプト出力前のコード抜け・廃止薬チェックまで自動で点検します。

GS1バーコード現物照合 アレルギー・相互作用警告 照合未了のまま完了させない保護 レセプト出力前チェック
POINT 03 — 在庫と発注が直結

「調剤中に薬が足りない」がその場で発注リストに。

ピッキング中に棚不足を記録すると、そのまま在庫画面の「発注ワークベンチ」に自動で集まります。発注点を下回った薬や期限が迫った薬も一覧でわかり、同じ効能の代替薬探しや納品書OCRでの入庫もスムーズです。

棚不足→発注リスト直結 代替薬のワンクリック検索 納品書OCR・卸CSV入庫 麻薬・向精神薬の棚卸
POINT 04 — コストゼロ＆ネット不調でも止まらない

月額費用0円。院内PCで動くから通信トラブルの日も安心。

高額な専用サーバーや月額ライセンス料は不要です。お店のパソコンの中で軽快に動作するため、光回線の不調時でも受付・薬歴・印刷が止まりません。受付や調剤室で複数台のタブレット・PCをつなぐ運用にも対応しています。

月額利用料・更新料 0円 オフラインでも業務継続 複数PC・タブレット連携 暗号化バックアップ

Daily Workflow

来局から会計・発注まで、薬局の1日の流れに沿って使えます。

難しい操作を覚える必要はありません。いつもの業務の順番通りに画面を進めるだけで、抜け漏れなく処理が終わります。

STEP 01 — 処方箋受付・患者呼び出し

処方箋を読み取り、原本と並べてスムーズに受付。

処方箋のQRコード読み取り、カメラ・画像からの文字読み取り（OCR）、マイナ資格確認端末の連携フォルダ取込、手入力に対応。 処方箋の画像と入力欄を左右に並べて見比べられるので、画面を切り替えずに確認できます。

  • 再来患者さんを自動で名寄せ — 氏名と生年月日から登録済みの患者さんを自動で探し出し、重複登録を防ぎます
  • 一般名処方【般】や公的用法マスタに標準対応 — よく使う用法の検索や、第1〜第3公費までの複数公費の入力・保持に対応しています
処方箋QR読取 カメラ・画像OCR マイナ結果XML取込 患者さんの自動名寄せ

STEP 02 — ピッキング・取り違え防止

棚番地通りに集めて、バーコードでピッと現物確認。

処方内容から「棚番地順」のピッキングリストを自動表示。薬の箱やシートのGS1バーコードを読み取るだけで、処方された薬と合っているか、使用期限が切れていないかをその場で判定します。

  • その場で「棚不足」を記録 — 在庫が足りないときはワンクリックで不足記録を残せ、後から発注画面でまとめて確認できます
  • 既存の調剤機器・ピッキング機とも連携 — ピッキング指示CSVの入出力や、NSIPS対応の分包機・調剤機器への処方送信に対応しています
棚番地順リスト GS1バーコード照合 使用期限・ロット確認 調剤機器・CSV連携

STEP 03 — 服薬指導・電子薬歴（SOAP）

前回との違いがすぐわかり、薬歴がサッと書ける。

「前回の薬歴」「今回変わった薬」「アレルギー・副作用歴」「飲み合わせの注意」が1つの画面にまとまっています。 服薬状況や残薬、副作用の有無をポチッと選ぶだけでSOAPの下書きが作られ、薬剤師が確認・手直ししてすぐに保存できます。

  • アレルギー・併用禁忌・重複投薬を自動チェック — 添付文書データをもとに、注意が必要な組み合わせや同効薬の重複をわかりやすく知らせます
  • 疑義照会・トレーシングレポートも1画面で — 疑義照会の記録や、処方医への服薬情報提供書の作成・印刷、来局後のフォローアップ予定までこの画面で完結します
4パネルSOAP薬歴 前回処方との差分表示 飲み合わせ・アレルギー警告 トレーシングレポート印刷

STEP 04 — 会計・帳票印刷・レセプト（UKE）出力

薬袋・手帳シールをすぐ印刷。レセプト前の点検も自動で。

令和8年（2026年）調剤報酬にもとづき、調剤基本料・薬剤調製料・各種加算や窓口負担金を自動計算。 領収証・明細書・薬袋・薬情・お薬手帳シールを必要な分だけ選んで、ブラウザから直接プリンターへ印刷できます。

  • 返戻を防ぐ「請求前ダブルチェック」 — レセプト（UKE）を作る前に、必須項目の抜けや経過措置切れの薬がないかを自動点検し、修正箇所を教えてくれます
  • 単票プレビュー＆月次一括UKE出力 — 1件ごとのUKEレコード内容の確認から、月末の審査支払機関向けUKEファイル一括出力、返戻・再請求の管理まで対応しています
令和8年調剤報酬算定 11種帳票ダイレクト印刷 UKE出力前エラー点検 返戻・再請求管理

STEP 05 — 在庫管理・発注ワークベンチ・棚卸

足りない薬・期限が近い薬を、自動でリストアップ。

「調剤で不足した薬」「発注点を切った薬」「使用期限が近い薬」が1つの画面に自動で集まります。 推奨発注数を参考にしながら発注CSVを出力でき、万が一の欠品時には同じ成分・同効の代替薬もすぐに探せます。

  • 納品書OCR＆バーコード入庫 — 卸の納品書をカメラや画像で読み取るか、箱のバーコードを読むだけで、ロット・使用期限つきの入庫登録が簡単に終わります
  • 麻薬・向精神薬の棚卸と不動在庫チェック — 帳簿残高と実在庫の突き合わせ記録や、動きのないデッドストックの抽出も標準で行えます
発注ワークベンチ 納品書OCR・CSV入庫 同効・代替薬の検索 麻薬・向精神薬棚卸

STEP 06 — 受付・調剤室・投薬カウンターでの複数端末連携

お店の複数PC・タブレットでも、安全に同時作業。

「受付で処方箋を入力しながら、調剤室でピッキングし、投薬カウンターで薬歴を書く」といった複数台での運用にも対応。 メインのPC1台にデータをまとめ、サブのタブレット等にはデータを残さない仕組みなので、端末の紛失や故障時も安心です。

  • 設定画面からワンクリックで端末追加・解除 — 難しいネットワーク構築なしで、店舗内LANでサブ端末を追加・管理できます
  • 同時編集時も上書き事故を防止 — 同じ患者さんの記録を別々の端末で同時に触ってしまった場合も、勝手に消えず確認画面で安全に見比べて反映できます
店舗内複数PC・タブレット対応 サブ端末にデータを残さない安心設計 同時編集の上書き防止

How It Works in Your Pharmacy

1台のPCからすぐ始められて、お店の規模に合わせて広げられます。

大がかりなサーバー工事や専用回線は必要ありません。お店のスタイルに合わせて、シンプルな構成で利用できます。

選べる2つの運用スタイル

① PC 1台でシンプルに使う（小規模薬局・お試しに） すぐ使えます
お店のPC 1台 → 受付・薬歴・帳票印刷・UKE出力 → 外付けUSB等へバックアップ
② 受付・調剤室・投薬カウンターの複数台で使う 店舗内LAN連携
メインPC（データを一括保管） ⇄ 受付PC・調剤室タブレット（画面操作のみ）
③ 既存のピッキング機・分包機・資格確認端末とつなぐ 機器・フォルダ連携
pharma-oss ⇄ 資格確認端末の共有フォルダ / 分包機（NSIPS・CSV）

※既存のレセコンを使いながら、「まずはピッキング照合や電子薬歴、在庫発注管理だけpharma-ossを使う」といった段階的な併用もスムーズに行えます。

Getting Started

まずは3分、架空のデモ患者さんで触ってみませんか？

面倒なアカウント登録や初期設定は不要です。最初から入っている練習用の患者データで、受付から薬歴・印刷まで一通り試せます。

パソコンで動かす場合（4行で起動） 
git clone https://github.com/pharma-oss/pharma-oss.git
cd pharma-oss
npm install
npm run dev
# → ブラウザで http://localhost:3000 を開く

いちばん簡単 パスワード設定なしで今すぐ体験

  1. アプリを開き、最初の画面にある「デモ患者で体験を始める」（または画面右上の「3分デモ」）をクリックします。
  2. ログイン不要のまま、架空の患者さん「デモ患者 みどり（68歳・ロキソプロフェン副作用歴あり・3剤処方）」の薬歴画面が開きます。
  3. ピッキング照合 → SOAP薬歴の入力 → 薬袋・薬情・明細書の印刷プレビューまで、実際の動きをそのまま体験できます。

練習の後片付け デモデータはワンクリックで消去

  1. 練習用のデモ患者データは、毎月のレセプト（UKE）請求や分包機連携には混ざらないよう自動で区別されています。
  2. 操作を一通り試したあとは、ダッシュボード上部の「デモデータを片づける」ボタンを押すだけで、いつでもきれいに消去できます。
Q. インターネット回線が切れても、本当に窓口業務を続けられますか？
はい。患者さんのデータや薬品マスタはお使いのパソコン内に保存されているため、万が一ネットが繋がらなくなっても、処方箋の読み取り、ピッキング照合、薬歴の入力、薬袋や領収証の印刷、レセプトの作成までそのまま続けられます。
Q. 受付のパソコンと、調剤室のタブレットで同時に使えますか？
はい。メインのパソコン1台にデータをまとめ、受付や調剤室のパソコン・タブレットから社内LAN経由でつないで同時に作業できます。サブの端末側には患者データを残さない仕組みになっているため、タブレットの管理も安心です。詳しい手順は 現場運用マニュアル でご案内しています。
Q. 薬価改定や新薬が出たときのマスタ更新は難しくありませんか？
アプリ内の「設定 > マスタ更新」画面から、支払基金のホームページで公開されている医薬品マスタファイル（CSVまたはZIP）を選ぶだけで更新できます。更新前後の変更点リストも自動で作られ、万が一間違えたファイルを取り込んでもワンクリックで元の状態に戻せます。
Q. 今使っているレセコンやピッキング機器と併用できますか？
はい。既存の患者・薬歴データのCSV取り込みに対応しているほか、ピッキングリストのCSV出力・結果取込や、NSIPS形式での調剤機器連携を備えています。「まずはバーコードでのピッキング照合や電子薬歴、発注管理から使い始める」といった段階的な導入も可能です。
